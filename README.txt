ANUGRAH ADKANE PORTFOLIO

Files:
- index.html: page structure and resume content
- style.css: responsive dark portfolio design
- script.js: mobile navigation, copyright year, reveal animation
- profile.jpg: your uploaded profile photo

HOW TO RUN:
1. Keep all three files in the same folder.
2. Open the folder in VS Code.
3. Open index.html with the Live Server extension, or double-click index.html.

BEFORE PUBLISHING:
- Replace the LinkedIn and GitHub href="#" values in index.html with your actual profile URLs.
- Your profile photo is included as profile.jpg. Keep it in the same folder as index.html.
- Verify all resume details and update any changes before publishing.
